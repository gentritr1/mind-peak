# Meditation Tracks & Pulse Analysis

This folder stores **meditation background audio** and the corresponding **analysis metadata** that drives the breathing orb animation.

## Files

- `*.mp3` – audio tracks bundled with the app.
- `track-01.meta.json` – JSON metadata generated by the analysis script for a specific track.
- `index.ts` – single registry that exposes an array of `MEDITATION_TRACKS` for the app.

## Adding a New Track (Step by Step)

1. **Copy the audio file**

   Place your mp3 in this folder, e.g.:

   - `assets/songs/my-new-track.mp3`

2. **Run the analysis script**

   From the project root:

   ```bash
   # Make sure your audio env is active
   cd /Users/gentlegen/Desktop/peak-mind-app
   source .audio-env/bin/activate

   python tools/analyze_track.py \
     "assets/songs/my-new-track.mp3" \
     --id track-02 \
     --label "My New Track" \
     --description "Short description for the picker" \
     --out "assets/songs/track-02.meta.json"
   ```

   This will create `track-02.meta.json` with:

   - `bpm`
   - `pulseDurationMs` – average pulse length in ms
   - `pulsesMs[]` – per-segment pulses used to shape the meditation orb animation

3. **Register the track in `index.ts`**

   In `assets/songs/index.ts`:

   ```ts
   let track02Source: any | undefined;
   let track02Meta: any | undefined;

   try {
     track02Source = require('./my-new-track.mp3');
   } catch {
     track02Source = undefined;
   }

   try {
     track02Meta = require('./track-02.meta.json');
   } catch {
     track02Meta = undefined;
   }

   // Later in MEDITATION_TRACKS:
   if (track02Source) {
     MEDITATION_TRACKS.push({
       id: track02Meta?.id ?? 'track-02',
       label: track02Meta?.label ?? 'My New Track',
       description: track02Meta?.description ?? 'Short description',
       source: track02Source,
       pulseDurationMs: track02Meta?.pulseDurationMs,
       pulsesMs: Array.isArray(track02Meta?.pulsesMs)
         ? (track02Meta?.pulsesMs as number[])
         : undefined,
     });
   }
   ```

4. **Use it in the app**

   - The Meditation Timer will show your new track under **Background audio**.
   - The orb animation will automatically adapt its pulse timing to the `pulseDurationMs` / `pulsesMs` from the JSON.

## Notes

- Analysis is **offline only** – it runs on your machine, not inside the app.
- You can tweak labels and descriptions in the JSON or in `index.ts` without re-running analysis.
- If the mp3 or meta JSON is missing, the corresponding track simply won’t appear in the picker; the app falls back gracefully.
